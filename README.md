# Unidades e módulos — VibeCode

Fonte oficial das lições do aplicativo VibeCode, de Emanuel Bonfim.

O catálogo completo fica em `content/catalog.json`. As unidades 1.1 e 1.2 reúnem 64 lições com textos, exemplos, guias, prática e revisão. O aplicativo consulta este repositório público automaticamente, sem login ou token.

Aplicativo e APK: [Vibecode-](https://github.com/emanoelb5-lgtm/Vibecode-).

O guia editorial e a validação do catálogo serão incluídos neste repositório.
